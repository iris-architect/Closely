Политика конфиденциальности приложения Closely (Версия 2.0)

Дата вступления в силу: 01.06.2026

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает приложение Closely, как они хранятся и кому передаются.

1. Какие данные обрабатывает приложение

Данные гардероба. Приложение обрабатывает данные, добавляемые пользователем, включая:

  • фотографии предметов гардероба
  • категории и теги
  • настройки приложения

Эти данные хранятся локально на устройстве пользователя и не передаются разработчику.

Данные для VIP-доступа. Для использования VIP-функций приложение обрабатывает номер мобильного телефона пользователя. Номер телефона передаётся и хранится в базе данных Firebase. Он используется исключительно для идентификации пользователя и привязки статуса VIP. Статус VIP хранится в Firebase в виде флага vip = true.

Платёжные данные. Оплата VIP-доступа осуществляется через ЮKassa. Обработка платежей может осуществляться с использованием инфраструктуры Яндекс Облака. Разработчик не получает и не хранит данные банковских карт. Платёжный провайдер обрабатывает платёжные данные в соответствии со своей собственной политикой конфиденциальности.

2. Передача данных третьим лицам

Данные гардероба (фотографии, теги, категории) не передаются третьим лицам.

Для обработки VIP-платежей и хранения статуса VIP используются следующие сторонние сервисы:

  • ЮKassa — платёжный сервис, обрабатывающий платежи.
  • Яндекс Облако — инфраструктура, используемая для обработки платежей.
  • Firebase (Google) — облачная база данных, в которой хранится номер телефона и флаг VIP.

Указанные сервисы обрабатывают данные в соответствии со своими политиками конфиденциальности.

Передача данных третьим лицам также может осуществляться в случаях, прямо предусмотренных законодательством.

3. Хранение данных

Данные гардероба хранятся локально на устройстве пользователя. Разработчик не имеет к ним доступа.

Номер телефона и статус VIP хранятся в Firebase и доступны разработчику для предоставления платного функционала. Срок хранения — до удаления по запросу пользователя или до прекращения работы приложения.

4. Удаление приложения и данных

При удалении приложения локальные данные гардероба удаляются без возможности восстановления.

Для удаления номера телефона и статуса VIP из Firebase необходимо обратиться к разработчику по указанному email. После получения запроса данные будут удалены из активных систем и резервных копий в течение 180 дней в соответствии со стандартной практикой Firebase[citation:1][citation:2].

5. Безопасность

Разработчик принимает разумные меры для обеспечения безопасности приложения. Однако ни один метод передачи данных через интернет и ни один метод электронного хранения не является абсолютно безопасным. Разработчик не может гарантировать абсолютную защиту данных.

Актуальная версия политики всегда доступна в приложении или на официальной странице приложения.

Privacy Policy for the Closely Application (Version 2.0)

Effective date: 01.06.2026

This Privacy Policy describes what data the Closely application processes, how it is stored, and to whom it is transferred.

1. What Data the Application Processes

Wardrobe Data. The application processes data added by the user, including:

  • photos of wardrobe items
  • categories and tags
  • application settings

This data is stored locally on the user's device and is not transferred to the developer.

VIP Access Data. To use VIP features, the application processes the user's mobile phone number. The phone number is transferred to and stored in a Firebase database. It is used solely for user identification and linking the VIP status. The VIP status is stored in Firebase as a flag vip = true.

Payment Data. Payment for VIP access is processed through YooKassa. Payment processing may also be handled using Yandex Cloud infrastructure. The developer does not receive or store bank card details. The payment provider processes payment data in accordance with its own privacy policy.

Wardrobe data (photos, tags, categories) is not shared with third parties.

  • Firebase (Google) — cloud database where the phone number and VIP flag are stored.

These services process data in accordance with their own privacy policies.

Data may also be shared with third parties where required by law.

Wardrobe data is stored locally on the user's device. The developer does not have access to it.

The phone number and VIP status are stored in Firebase and are accessible to the developer to provide paid functionality. The retention period lasts until deletion upon user request or until the application is discontinued.

When the application is removed, locally stored wardrobe data is deleted without the possibility of recovery.
